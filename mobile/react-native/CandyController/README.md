## Running the app

- Install the dependencies:

  ```sh
  npx expo install
  ```

- Build and run iOS and Android development builds:

  ```sh
  npx expo run:ios
  # or
  npx expo run:android
  ```

- In the terminal running the development server, press `j` to open the Dev Tools.

- Clean the native packages:

  ```sh
  npx expo prebuild --clean
  ```
